SECTION 5: The Python Orchestrator — Deep Dive (Part 2: The Graph & Agent Nodes)

Welcome back! In Part 1, we learned how our system communicates and stores data. Now, we are going to look at the "brains" of the operation. How do we take a simple user request like "Create a trading strategy" and turn it into actual, functioning, highly optimized C++ code?

The answer is an AI Agent Swarm powered by a graph framework. In this section, we will look at exactly how the orchestrator guides AI agents to act like a real-world quantitative trading firm, complete with researchers, developers, and evaluators.

graph.py: The Blueprint of our Swarm

What is a State Machine?

Imagine a traffic light. It has specific states: Green, Yellow, and Red. It can only transition between these states in a very specific order (Green -> Yellow -> Red -> Green). It never jumps directly from Green to Red. This is a State Machine—a system that exists in one specific "state" at a time and follows strict rules about how it can change from one state to another.

In our project, the AI swarm is a state machine. It moves through specific steps (Research -> Code -> Evaluate), carrying data along with it, and deciding what to do next based on the rules we define.

What is LangGraph and StateGraph?

LangGraph is a Python library built on top of LangChain. While LangChain is great for a single AI chat interaction, LangGraph is designed to build complex, multi-agent workflows. StateGraph is a tool inside LangGraph that lets us define the nodes (the agents doing the work) and the edges (the rules for passing work to the next agent).

Python Tip: What is partial()? Normally, when you pass a function as an argument, you can't pass its arguments at the same time. partial() from the functools library lets you pre-fill some of a function's arguments. For example, partial(coder_node, settings=settings) creates a new version of the coder_node function that already has settings attached to it.

The Code: graph.py

from functools import partial
from langgraph.graph import END, StateGraph
from swarm_orchestrator.config import Settings
from swarm_orchestrator.nodes.coder import coder_node
from swarm_orchestrator.nodes.evaluator import should_reflect, submit_and_evaluate_node
from swarm_orchestrator.nodes.researcher import researcher_node
from swarm_orchestrator.state import SwarmState

def build_graph(settings=None):
    settings = settings or Settings()
    graph = StateGraph(SwarmState)
    graph.add_node("researcher", partial(researcher_node, settings=settings))
    graph.add_node("coder", partial(coder_node, settings=settings))
    graph.add_node("evaluator", partial(submit_and_evaluate_node, settings=settings))
    graph.set_entry_point("researcher")
    graph.add_edge("researcher", "coder")
    graph.add_edge("coder", "evaluator")
    graph.add_conditional_edges("evaluator", should_reflect, {"coder": "coder", "end": END})
    return graph.compile()

Line-by-Line Walkthrough:

  • def build_graph(settings=None): — We define a function that will build and return our AI workflow graph.
  • settings = settings or Settings() — If no settings are provided, we initialize the default settings.
  • graph = StateGraph(SwarmState) — We create a new graph. We pass it SwarmState, which is the data structure (like a shared dictionary) that will be passed from agent to agent.
  • graph.add_node("researcher", ...) — We create a node called "researcher" and assign it the researcher_node function. We use partial to pre-inject the settings.
  • graph.add_node("coder", ...) and graph.add_node("evaluator", ...) — We create the coder and evaluator nodes exactly like the researcher node.
  • graph.set_entry_point("researcher") — We tell the graph that whenever it starts running, it MUST start at the researcher node.
  • graph.add_edge("researcher", "coder") — This creates a direct path. When the researcher finishes, the graph always moves to the coder.
  • graph.add_edge("coder", "evaluator") — When the coder finishes, it always moves to the evaluator.
  • graph.add_conditional_edges(...) — This is the magic! After the evaluator finishes, it calls the should_reflect function. If that function returns "coder", the graph loops back to the coder. If it returns "end", the workflow finishes!
  • return graph.compile() — This finalizes the graph structure into a runnable application.

nodes/researcher.py: The Brainstormer

Think of the Researcher Node as the senior Quantitative Analyst at a hedge fund. They don't write the final optimized C++ code. Instead, they look at the market, come up with a brilliant mathematical theory (the "hypothesis"), and write a specification detailing what assets to trade and what rules to follow.

What is a UUID?

A UUID (Universally Unique Identifier) is a 36-character string of random letters and numbers (e.g., 123e4567-e89b-12d3-a456-426614174000). We use UUIDs because when you have hundreds of trading strategies running across multiple servers, you need a way to guarantee that no two strategies accidentally get the same ID number.

The Code: researcher.py

"""REQ-1.1: Researcher Node — generate strategy hypotheses."""

from __future__ import annotations

import json
import uuid

from langchain_core.messages import HumanMessage, SystemMessage

from swarm_orchestrator.broker.crdt_state import SwarmStateCRDT
from swarm_orchestrator.config import Settings
from swarm_orchestrator.llm_factory import create_llm
from swarm_orchestrator.prompts import RESEARCHER_SYSTEM
from swarm_orchestrator.state import StrategyHypothesis, SwarmState


def researcher_node(state: SwarmState, settings: Settings) -> dict:
    task_id = state.get("task_id") or str(uuid.uuid4())
    llm = create_llm(settings)

    prompt = state.get("user_prompt") or "Design a mean-reversion strategy for liquid US equities."
    response = llm.invoke([
        SystemMessage(content=RESEARCHER_SYSTEM),
        HumanMessage(content=prompt),
    ])

    try:
        data = json.loads(response.content)
        hypothesis = StrategyHypothesis.model_validate(data)
    except (json.JSONDecodeError, ValueError):
        hypothesis = StrategyHypothesis(
            name="Generated Strategy",
            description=response.content.strip(),
            symbols=["SPY"],
        )

    crdt = SwarmStateCRDT(settings.redis_url, settings.crdt_node_id or None)
    crdt.update_register(task_id, "hypothesis", hypothesis.model_dump())
    if settings.enable_crdt_sync:
        crdt.publish_for_sync(task_id)

    return {
        "task_id": task_id,
        "hypothesis": hypothesis,
        "iteration_log": [f"[researcher] Hypothesis: {hypothesis.name}"],
    }

Line-by-Line Walkthrough:

  • def researcher_node(state: SwarmState, settings: Settings) -> dict: — The node takes the current graph state and settings, and returns a dictionary that updates the state.
  • task_id = state.get("task_id") or str(uuid.uuid4()) — If this task doesn't have an ID yet, we generate a random UUID for it.
  • llm = create_llm(settings) — We boot up our AI model (like GPT-4 or Claude) using our system settings.
  • prompt = state.get("user_prompt") or "Design a mean-reversion..." — We get what the user asked for. If the user didn't ask for anything, we use a default prompt.
  • response = llm.invoke([...]) — This is where we actually talk to the AI. We send it a SystemMessage (which contains strict instructions on how to behave, imported from RESEARCHER_SYSTEM) and a HumanMessage (the user's prompt).
  • try: ... except: ... — We expect the AI to return data in JSON format so we can turn it into a Python object (StrategyHypothesis.model_validate). But what if the LLM messes up and just returns plain text?
  • Error Handling: In the except block, if the JSON parsing fails, we create a fallback StrategyHypothesis manually, taking whatever text the AI gave us and applying it to the default symbol "SPY". The system won't crash!
  • crdt = SwarmStateCRDT(...) — We initialize our CRDT (Conflict-free Replicated Data Type) to store this data in Redis, ensuring all servers know about this new hypothesis.
  • return { ... } — We return the new data. LangGraph will take this dictionary and merge it into the main SwarmState, carrying it forward to the Coder node.

nodes/coder.py: The Software Engineer

If the Researcher is the analyst, the Coder Node is the Software Engineer. The Coder doesn't question the math; its job is to take the Researcher's spec and translate it into flawless, ultra-fast C++ code. If the code breaks during testing, the Coder gets the error report and has to fix it.

The Code: coder.py

"""REQ-1.2: Coder Node — generate C++ strategy conforming to StrategyInterface.hpp."""

from __future__ import annotations

from langchain_core.messages import HumanMessage, SystemMessage

from swarm_orchestrator.broker.crdt_state import SwarmStateCRDT
from swarm_orchestrator.broker.redis_cache import AgentMemoryCache
from swarm_orchestrator.config import Settings
from swarm_orchestrator.llm_factory import create_llm
from swarm_orchestrator.prompts import CODER_SYSTEM
from swarm_orchestrator.state import SwarmState


def _strip_fences(text: str) -> str:
    lines = text.strip().splitlines()
    if lines and lines[0].startswith("```"):
        lines = lines[1:]
    if lines and lines[-1].startswith("```"):
        lines = lines[:-1]
    return "\n".join(lines)


def coder_node(state: SwarmState, settings: Settings) -> dict:
    task_id = state.get("task_id", "")
    crdt = SwarmStateCRDT(settings.redis_url, settings.crdt_node_id or None)
    if settings.enable_crdt_sync:
        crdt.subscribe_sync(task_id)

    cache = AgentMemoryCache(settings.redis_url)
    history = crdt.format_iteration_log(task_id) or cache.format_for_prompt(task_id)

    llm = create_llm(settings)

    hypothesis_text = ""
    hypothesis = state.get("hypothesis")
    if hypothesis:
        hypothesis_text = hypothesis.model_dump_json(indent=2)

    reflection = ""
    if state.get("reflection_notes"):
        reflection = f"\n\nFix these issues from the evaluator:\n{state['reflection_notes']}"
    outcome = state.get("outcome")
    if outcome and outcome.stderr:
        reflection += f"\n\nCompiler/runtime stderr:\n{outcome.stderr[:4000]}"

    response = llm.invoke([
        SystemMessage(content=CODER_SYSTEM),
        HumanMessage(content=f"{history}\n\nHypothesis:\n{hypothesis_text}{reflection}"),
    ])

    source = _strip_fences(response.content)
    iteration = state.get("iteration", 0)

    crdt.update_register(task_id, "strategy_source", source)
    crdt.append_iteration(task_id, {
        "iteration": iteration,
        "status": "coded",
        "notes": f"Generated strategy for {hypothesis.name if hypothesis else 'unknown'}",
    })
    if settings.enable_crdt_sync:
        crdt.publish_for_sync(task_id)

    cache.append_iteration(task_id, {
        "iteration": iteration,
        "status": "coded",
        "notes": f"Generated strategy for {hypothesis.name if hypothesis else 'unknown'}",
    })

    return {
        "strategy_source": source,
        "iteration": iteration + 1,
        "iteration_log": [f"[coder] Iteration {iteration + 1} source generated ({len(source)} bytes)"],
    }

Line-by-Line Walkthrough:

  • def _strip_fences(text: str) -> str: — Large Language Models (like ChatGPT) love to wrap code in markdown formatting (like ```cpp ... ```). We can't feed markdown backticks into a C++ compiler! This helper function simply looks at the first and last lines of the text and removes those backticks if they exist.
  • history = crdt.format_iteration_log(...) — Iteration Memory: If the coder makes a mistake and the loop runs again, we load the "history". This prevents the LLM from making the exact same mistake twice. It gives the AI a memory of what it just tried.
  • hypothesis_text = hypothesis.model_dump_json(indent=2) — We convert the researcher's hypothesis object back into readable JSON text so the LLM can understand it.
  • reflection = ... — Reflection Notes: If the graph looped backward, the Evaluator node will have left notes detailing exactly what failed (e.g., "The code compiled, but it traded too much and lost money"). We append this to the prompt.
  • outcome.stderr[:4000] — If the C++ compiler actually threw an error, we capture the standard error (stderr) output and feed the first 4,000 characters directly to the AI so it can debug its own code!
  • response = llm.invoke(...) — We ask the LLM to write the C++ code based on the history, hypothesis, and any error reflections.
  • source = _strip_fences(response.content) — We clean the markdown off the AI's response to get pure C++ source code.
  • "iteration": iteration + 1 — We increment the iteration counter. This ensures we don't end up in an infinite loop.

nodes/evaluator.py: The Quality Inspector

The Evaluator Node is the Quality Assurance Inspector on an assembly line. When a product (the C++ code) comes down the line, the inspector runs rigorous tests on it. If it fails, the inspector sends it back to the manufacturer (the Coder) with a detailed note on what to fix. If it passes, it gets stamped "Approved" and placed in the warehouse (MongoDB database).

This file is highly complex because it forms a bridge between our Python orchestrator and our high-performance C++ backtesting engine (which is discussed in another section). They communicate using a message queue (RabbitMQ).

The Code: evaluator.py

"""REQ-1.3 / REQ-1.4: Evaluator Node and reflection routing."""

from __future__ import annotations

import json
import time

import pika
from langchain_core.messages import HumanMessage, SystemMessage
from pymongo import MongoClient

from swarm_orchestrator.broker.crdt_state import SwarmStateCRDT
from swarm_orchestrator.broker.rabbitmq import (
    BacktestResultPayload,
    BacktestTaskPayload,
    RESULT_QUEUE,
    declare_topology,
    parse_result,
    publish_task,
)
from swarm_orchestrator.broker.redis_cache import AgentMemoryCache
from swarm_orchestrator.config import Settings
from swarm_orchestrator.llm_factory import create_llm
from swarm_orchestrator.prompts import EVALUATOR_SYSTEM
from swarm_orchestrator.state import BacktestMetrics, BacktestOutcome, SwarmState


def _wait_for_result(channel: pika.adapters.blocking_connection.BlockingChannel, task_id: str, timeout: float) -> BacktestResultPayload | None:
    deadline = time.time() + timeout
    while time.time() < deadline:
        method, _, body = channel.basic_get(queue=RESULT_QUEUE, auto_ack=True)
        if method is None:
            time.sleep(0.25)
            continue
        result = parse_result(body)
        if result.task_id == task_id:
            return result
    return None


def submit_and_evaluate_node(state: SwarmState, settings: Settings) -> dict:
    """Publish backtest task, wait for result, evaluate KPIs."""
    cache = AgentMemoryCache(settings.redis_url)

    params = pika.URLParameters(settings.rabbitmq_url)
    connection = pika.BlockingConnection(params)
    channel = connection.channel()
    declare_topology(channel)

    hypothesis = state.get("hypothesis")
    task = BacktestTaskPayload(
        task_id=state.get("task_id", ""),
        iteration=state.get("iteration", 0),
        strategy_source=state.get("strategy_source", ""),
        dataset_id=state.get("dataset_id", "sample_spy_ticks"),
        metadata={
            "hypothesis": hypothesis.description if hypothesis else "",
            "symbols": hypothesis.symbols if hypothesis else [],
        },
    )
    publish_task(channel, task)

    task_id = state.get("task_id", "")
    raw = _wait_for_result(channel, task_id, settings.backtest_timeout_sec)
    connection.close()

    if raw is None:
        outcome = BacktestOutcome(task_id=task_id, status="timeout", stderr="Backtest result timeout")
    else:
        metrics = None
        if raw.metrics:
            metrics = BacktestMetrics(**raw.metrics)
        outcome = BacktestOutcome(
            task_id=raw.task_id,
            status=raw.status,  # type: ignore[arg-type]
            metrics=metrics,
            stderr=raw.stderr,
            stdout=raw.stdout,
        )

    approved = False
    reflection = ""

    if outcome.status != "success":
        reflection = f"Execution failed with status={outcome.status}. stderr: {outcome.stderr[:2000]}"
    elif outcome.metrics:
        m = outcome.metrics
        failures = []
        if m.max_drawdown_pct > settings.max_drawdown_pct:
            failures.append(f"Max drawdown {m.max_drawdown_pct:.2f}% exceeds {settings.max_drawdown_pct}%")
        if m.avg_latency_us > settings.max_latency_us:
            failures.append(f"Avg latency {m.avg_latency_us:.2f}µs exceeds {settings.max_latency_us}µs")
        if m.sharpe_ratio < settings.min_sharpe_ratio:
            failures.append(f"Sharpe {m.sharpe_ratio:.2f} below minimum {settings.min_sharpe_ratio}")

        if failures:
            reflection = "; ".join(failures)
        else:
            approved = True

    if not approved and not reflection:
        llm = create_llm(settings)
        eval_input = json.dumps(outcome.model_dump(), indent=2)
        response = llm.invoke([
            SystemMessage(content=EVALUATOR_SYSTEM),
            HumanMessage(content=eval_input),
        ])
        reflection = response.content.strip()

    cache.append_iteration(task_id, {
        "iteration": state.get("iteration", 0),
        "status": outcome.status,
        "notes": reflection or "approved",
        "metrics": outcome.metrics.model_dump() if outcome.metrics else None,
    })

    crdt = SwarmStateCRDT(settings.redis_url, settings.crdt_node_id or None)
    crdt.update_register(task_id, "reflection_notes", reflection)
    crdt.append_iteration(task_id, {
        "iteration": state.get("iteration", 0),
        "status": outcome.status,
        "notes": reflection or "approved",
        "metrics": outcome.metrics.model_dump() if outcome.metrics else None,
    })
    if settings.enable_crdt_sync:
        crdt.publish_for_sync(task_id)

    if approved:
        try:
            client = MongoClient(settings.mongodb_url)
            db = client.get_default_database()
            hypothesis = state.get("hypothesis")
            db.strategies.insert_one({
                "task_id": task_id,
                "hypothesis": hypothesis.model_dump() if hypothesis else None,
                "strategy_source": state.get("strategy_source", ""),
                "metrics": outcome.metrics.model_dump() if outcome.metrics else None,
            })
        except Exception:
            pass

    return {
        "outcome": outcome,
        "approved": approved,
        "reflection_notes": reflection,
        "iteration_log": [f"[evaluator] status={outcome.status} approved={approved}"],
    }


def should_reflect(state: SwarmState) -> str:
    """REQ-1.4: Reflection edge — route back to coder or end."""
    if state.get("approved"):
        return "end"
    if state.get("iteration", 0) >= state.get("max_iterations", 5):
        return "end"
    return "coder"

Line-by-Line Walkthrough:

  • def _wait_for_result(...) — The Polling Pattern: Once we send the C++ code to be tested, it takes time. This function loops constantly (a while loop). It checks the RabbitMQ message queue. If it finds a message matching our task_id, it grabs it. If it doesn't find it, it sleeps for a quarter of a second and checks again until the deadline is reached.
  • task = BacktestTaskPayload(...) — We package up the C++ code (strategy_source) and other metadata into a structured payload.
  • publish_task(channel, task) — We send the package over RabbitMQ to the C++ engine.
  • raw = _wait_for_result(...) — We wait for the C++ engine to finish simulating the strategy and return the results.
  • KPI Checking Logic: If the code ran successfully, we check the financial metrics (Key Performance Indicators):
    • Max Drawdown: What was the largest percentage drop from peak to trough in our portfolio? If it drops more than our setting (e.g., 20%), the strategy is too risky.
    • Average Latency: How fast did our C++ code execute? If it's slower than our setting (e.g., 100 microseconds), it will lose in High-Frequency Trading.
    • Sharpe Ratio: This is a financial metric that measures risk-adjusted return. A higher Sharpe ratio means better, safer profits. If it's below our minimum, the strategy isn't good enough.
  • if not approved and not reflection: — AI Evaluation: If the strategy failed our checks, but we didn't generate a clear string of reasons why, we actually boot up an LLM here! We ask the LLM Evaluator to look at the financial data and write a critique for the Coder on why it failed financially, so the Coder can try a different approach.
  • db.strategies.insert_one(...) — MongoDB Storage: If the strategy passes ALL checks, congratulations! It's a profitable, lightning-fast algorithmic trading strategy. We save the code and its financial metrics into our NoSQL MongoDB database so it can be deployed to live markets.
  • def should_reflect(state: SwarmState) -> str: — This is the decision function we attached to the graph earlier.
    • If approved is True, return "end" (we finished successfully).
    • If we have looped more times than max_iterations (usually 5), return "end" (we give up so we don't spend forever in an infinite loop).
    • Otherwise, return "coder" (send it back to the coder node with the reflection notes to try again).

By chaining these three nodes together, we have created an autonomous system that can dream up trading ideas, write the high-speed code for them, rigorously backtest them, debug them if they fail, and store them securely if they succeed!
